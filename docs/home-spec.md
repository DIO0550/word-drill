# Word Drill - ホーム画面仕様（フロントエンド）

> **機能**: [Word Drill](./index.md)
> **ステータス**: 下書き

## 概要

アプリのエントリーポイントとなるホーム画面。メインカテゴリの一覧をカード形式で表示し、学習したい分野へのナビゲーションを提供する。

## ページ構成

| ページ | URL | 説明 |
|:-------|:----|:-----|
| ホーム | `/` | メインカテゴリ一覧の表示 |

## コンポーネント

| コンポーネント | 種別 | 説明 | 振る舞い |
|:-------------|:-----|:-----|:---------|
| HomePage | ページ | ホーム画面全体のコンテナ | ヒーロー + カテゴリ一覧を描画 |
| HeroSection | セクション | タイトルと説明文の表示 | アイコン「📖」、タイトル「英単語ドリル」、説明「カテゴリを選んで学習を始めよう」を表示 |
| MainCategoryCard | カード | メインカテゴリの情報表示 | カテゴリ名、説明、サブカテゴリ数、単語数、サブカテゴリタグを表示。クリックで設定画面に遷移 |

### MainCategoryCard の表示内容

| 表示要素 | ソース | フォーマット | 空の場合 |
|:---------|:-------|:------------|:---------|
| アイコン | `category.icon` | 絵文字 | - |
| カテゴリ名 | `category.name` | テキスト | - |
| 説明 | `category.description` | テキスト | - |
| サブカテゴリ数 | `category.subCategories.length` | `{N}カテゴリ` | - |
| 総単語数 | 全サブカテゴリの`wordCount`合計 | `{N}単語` | `0単語` |
| サブカテゴリタグ | 先頭3つの`subCategory.name` | タグ形式 | - |
| 追加数表示 | 4つ以上の場合 | `+{N}` | 表示なし |

## ユーザー操作

| 操作 | トリガー | 振る舞い | 遷移先 |
|:-----|:--------|:---------|:-------|
| カテゴリ選択 | MainCategoryCardをクリック | カテゴリ設定画面に遷移 | `/category/{categoryId}` |
| 統計ページへ | ヘッダーの「統計」リンクをクリック | 統計画面に遷移 | `/stats` |
| テーマ変更 | ヘッダーのテーマ切り替えを操作 | アプリ全体のテーマが変更される | - |

## 状態管理

このページはローカル状態を持たない。カテゴリデータは静的にインポートされる。

### データソース

| データ | ソース | 型 |
|:-------|:-------|:---|
| メインカテゴリ一覧 | `src/features/category/data/categories.ts` | `MainCategory[]` |

### MainCategory 型

```typescript
type MainCategory = {
  id: string            // カテゴリID（例: "english"）
  name: string          // 表示名（例: "英単語"）
  description: string   // 説明文
  icon: string          // 絵文字アイコン
  subCategories: SubCategory[]
}
```

## メインカテゴリ一覧

|:---|:-----|:--------|:-----|:-------------|

## レスポンシブ対応

| ブレークポイント | レイアウト変更 |
|:---------------|:-------------|
| モバイル（〜767px） | カテゴリカードは1列表示。ヒーローセクションのフォントサイズ縮小 |
| タブレット（768〜1023px） | カテゴリカードは2列グリッド |
| デスクトップ（1024px〜） | カテゴリカードは2〜3列グリッド。最大幅制限あり |

## アクセシビリティ

| 観点 | 対応方針 |
|:-----|:---------|
| キーボード操作 | Tab でカテゴリカード間を移動、Enter/Space で選択 |
| スクリーンリーダー | カテゴリカードは `<a>` 要素でリンクとして認識可能。カテゴリ名と説明を読み上げ |
| カラーコントラスト | テキストと背景のコントラスト比 4.5:1 以上（WCAG AA） |
| フォーカス管理 | カテゴリカードにフォーカスリングを表示 |
| ランドマーク | ヒーローセクションに `role="banner"` または `<header>`、カテゴリ一覧に `<main>` |

## 制限事項

- カテゴリデータは静的にコード内に定義されており、動的な追加・編集はできない
- 各サブカテゴリの `wordCount` は現在すべて 0（クイズデータ読み込み実装後に反映予定）
