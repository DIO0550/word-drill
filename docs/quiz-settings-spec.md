# Word Drill - クイズ設定画面仕様（フロントエンド）

> **機能**: [Word Drill](./index.md)
> **ステータス**: 下書き

## 概要

クイズ開始前の設定画面。ユーザーがサブカテゴリ、問題数、クイズモードを選択してからクイズを開始する。

## ページ構成

| ページ | URL | 説明 |
|:-------|:----|:-----|
| クイズ設定 | `/category/:categoryId` | サブカテゴリ・問題数・モード選択 |

## ルートパラメータ

| パラメータ | 型 | 説明 | 例 |
|:----------|:---|:-----|:---|
| `categoryId` | string | メインカテゴリのID | `english`, `programming`, `it` |

## コンポーネント

| コンポーネント | 種別 | 説明 | 振る舞い |
|:-------------|:-----|:-----|:---------|
| CategorySettingsPage | ページ | 設定画面全体のコンテナ | カテゴリ情報とフォームを描画 |
| BackButton | ボタン | ホームへの戻るリンク | クリックでホーム (`/`) に遷移 |
| CategoryHeader | セクション | カテゴリアイコン・名前・開始ボタン | カテゴリ情報と開始アクションを表示 |
| SubCategoryRadioGroup | ラジオグループ | サブカテゴリ選択 | ラジオボタンでサブカテゴリを1つ選択 |
| QuestionCountRadioGroup | ラジオグループ | 問題数選択 | 10 / 20 / すべて から選択 |
| QuizModeRadioGroup | ラジオグループ | クイズモード選択 | 3つのモードから選択 |

## フォーム仕様

### フィールド定義

| フィールド | 種別 | 必須 | 初期値 | 説明 |
|:----------|:-----|:-----|:-------|:-----|
| subCategory | ラジオボタン | はい | 未選択 (`null`) | 学習対象のサブカテゴリ |
| questionCount | ラジオボタン | はい | `10` | 出題する問題の数 |
| quizMode | ラジオボタン | はい | `term-to-meaning` | 出題形式 |
| shuffle | ラジオボタン | はい | `true` (ON) | 出題順のシャッフル |

### サブカテゴリ選択肢

選択肢はメインカテゴリの `subCategories` から動的に生成される。

各選択肢に表示する情報:
| 表示要素 | ソース |
|:---------|:-------|
| アイコン | `subCategory.icon` |
| 名前 | `subCategory.name` |
| 説明 | `subCategory.description` |
| 単語数 | `subCategory.wordCount` |

### 問題数の選択肢

| ラベル | 値 | 説明 |
|:-------|:---|:-----|
| 10問 | `10` | 10問を出題 |
| 20問 | `20` | 20問を出題 |
| すべて | `all` | カテゴリ内の全問題を出題 |

### クイズモードの選択肢

| ラベル | 値 | 説明 |
|:-------|:---|:-----|
| 用語 → 意味 | `term-to-meaning` | 用語を表示し、意味を4択で選ぶ |
| 意味 → 用語 | `meaning-to-term` | 意味を表示し、用語を4択で選ぶ |
| ランダム | `random` | クイズ開始時にランダムにモードを1つ決定（全問同じモードで出題） |

### シャッフルの選択肢

| ラベル | 値 | 説明 |
|:-------|:---|:-----|
| ON | `true` | 出題順をランダムに並び替える（デフォルト） |
| OFF | `false` | ファイル内の定義順で出題する |

### バリデーションルール

| フィールド | ルール | エラーメッセージ | タイミング |
|:----------|:------|:---------------|:----------|
| subCategory | 必須（null不可） | サブカテゴリを選択してください | 開始ボタン押下時 |

### 送信時の動作

| アクション | 遷移先 | パラメータ |
|:----------|:-------|:----------|
| 「開始する」ボタン押下 | `/quiz/{categoryId}/play` | `subCategoryId`, `questionCount`, `quizMode`, `shuffle` をsearch paramsとして付与 |

**遷移時のURL例**:
```
/quiz/english/play?subCategoryId=en-toeic&questionCount=20&quizMode=term-to-meaning&shuffle=true
```

## 状態管理

### ページの状態

| 状態名 | 型 | 初期値 | 更新トリガー |
|:-------|:---|:-------|:-----------|
| selectedSubCategory | `SubCategory \| null` | `null` | サブカテゴリのラジオボタン選択 |
| questionCount | `QuestionCount` | `10` | 問題数のラジオボタン選択 |
| quizMode | `QuizMode` | `'term-to-meaning'` | モードのラジオボタン選択 |
| shuffle | `boolean` | `true` | シャッフルのラジオボタン選択 |

### QuestionCount 型

```typescript
type QuestionCount = 10 | 20 | 'all'
```

**ファクトリ関数** (`QuestionCount.from`):
- 有効な数値/文字列 → 対応する `QuestionCount` を返す
- 無効な値 → デフォルト `10` を返す

### QuizMode 型

```typescript
type QuizMode = 'term-to-meaning' | 'meaning-to-term' | 'random'
```

**ファクトリ関数** (`QuizMode.from`):
- 有効な文字列 → 対応する `QuizMode` を返す
- 無効な値 → デフォルト `'term-to-meaning'` を返す

## ユーザー操作

| 操作 | トリガー | 振る舞い | 遷移先 |
|:-----|:--------|:---------|:-------|
| 戻る | 「← 戻る」ボタンをクリック | ホーム画面に遷移 | `/` |
| サブカテゴリ選択 | ラジオボタンをクリック | `selectedSubCategory` を更新 | - |
| 問題数変更 | ラジオボタンをクリック | `questionCount` を更新 | - |
| モード変更 | ラジオボタンをクリック | `quizMode` を更新 | - |
| シャッフル変更 | ラジオボタンをクリック | `shuffle` を更新 | - |
| 開始 | 「開始する →」ボタンをクリック | サブカテゴリ未選択なら無効。選択済みならクイズ画面に遷移 | `/quiz/{categoryId}/play?...` |

## 表示データ

| フィールド | ソース | フォーマット | 空の場合 |
|:----------|:-------|:------------|:---------|
| カテゴリアイコン | `mainCategory.icon` | 絵文字 | - |
| カテゴリ名 | `mainCategory.name` | テキスト | - |
| サブカテゴリ一覧 | `mainCategory.subCategories` | ラジオボタンリスト | 表示なし |

### カテゴリデータの取得

`categoryId` パラメータを使って `mainCategories` 配列から該当するメインカテゴリを検索する。
該当するカテゴリが見つからない場合はホーム画面にリダイレクトする。

## レスポンシブ対応

| ブレークポイント | レイアウト変更 |
|:---------------|:-------------|
| モバイル（〜767px） | メインセクションとサイドバーを縦並びに変更。サブカテゴリ選択→設定（問題数・モード）の順に表示 |
| タブレット（768〜1023px） | 2カラムレイアウト（メイン:サイドバー = 2:1） |
| デスクトップ（1024px〜） | 2カラムレイアウト。最大幅制限あり |

## アクセシビリティ

| 観点 | 対応方針 |
|:-----|:---------|
| キーボード操作 | Tab でフォーム要素間を移動。ラジオグループ内は矢印キーで切り替え。Enter で「開始する」 |
| スクリーンリーダー | ラジオグループに `role="radiogroup"` と適切な `aria-label`（「サブカテゴリ選択」「問題数」「クイズモード」「シャッフル」） |
| カラーコントラスト | 選択状態と非選択状態の視覚的区別。テキストコントラスト比 4.5:1 以上 |
| フォーカス管理 | ページ遷移時にコンテンツエリアの先頭にフォーカス。「開始する」ボタンにフォーカスリング表示 |
| エラー通知 | サブカテゴリ未選択で開始した場合、`aria-live="polite"` でエラーを通知 |

## 制限事項

- 現在、クイズデータはモックデータを使用しており、設定した `subCategoryId` に対応する問題の動的読み込みは未実装
- 「すべて」を選択した場合の問題数上限は未定義
- サブカテゴリの `wordCount` は現在すべて 0
